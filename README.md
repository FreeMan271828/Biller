# BillCount

## V1.0.0

通过账单截图自动化生成记录

## 架构

![架构.drawio.png](../%E6%9E%B6%E6%9E%84.drawio.png)

## 功能

1. 对于每一家账单，根据特征把识别出的文本转变成账单，包括如下的函数
   - 数据自定义预处理（多个）
   - 提取金额函数
   - 主处理函数
   - 数据自定义后处理（多个）
2. 支持微信记账本和hiklink的账单处理
